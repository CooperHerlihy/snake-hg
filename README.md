# Snake HG

## Description

Snake, written to test basic usage of Hurdy Gurdy 2D

## Build

### Linux

Dependencies:
- Make
- C++ compiler (GCC or Clang)
- GLSL compiler (glslc)
- SDL3
- Vulkan Validation Layers (debug mode)

To build, run make:

```bash
make
```

To build in release mode, add `release` when running make:

```bash
make release
```
